# DrawingBoardThingy
It is a infinite canvas made with LÖVE.
## Features
- infinite canvas
- brush
- eraser
- layers
- multiplayer
## Controls
| Action | Input |
| --- | --- |
| use tool | LMB |
| pan | MMB |
| zoom | mouse wheel |
### Things that might get added later
- seeing other's cursor, color, name, and tool
- top right menu button menu
