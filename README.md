# DrawingBoardThingy
It is a infinite canvas made with LÖVE.
## Features
- infinite canvas
- brush
- eraser
- layers
- multiplayer
- see other people's cursors
## Controls
| Action | Input |
| --- | --- |
| use tool | LMB |
| pan | MMB |
| zoom | mouse wheel |
